# Gerenciamento-de-Hotel

Este projeto é responsável por gerenciamento de hotel , desenvolvido em java utilizando vetores , arrays e funções introdutórias ao Java.

Funcionalidades:

1-Reservar Quarto

Na opção reservar quarto o admnistrador deve digitar o número do quarto (1 a 100) e o nome do hospede.


2- Cancelar Reserva

Na opção cancelar reserva o administrador deve digitar a reserva para excluir o hospede dos dados.

obs: a reserva é gerada aleatóriamente em 6 digitos  , NECESSÁRIO LISTAR RESERVAS.
